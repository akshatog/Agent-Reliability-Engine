### 🧪 Key Fixes Applied (Post-Review)

1. **LLM Provider Overhaul:** Moving to Groq's `AsyncGroq` client with `response_format={"type": "json_object"}` completely resolved the `404` parsing errors during scenario generation. **19/19 backend tests patched to mock the new Groq client properly.**
2. **CI Pipeline:** `ci.yml` updated to inject the new `GROQ_API_KEY` GitHub Action Secret instead of the deprecated Gemini key.
3. **WebSocket Connect:** Fixed URL mismatch (`/ws/trace` → `/ws/traces`) enabling live streaming.
4. **Data Binding Types:** Fixed mismatches between backend JSON and frontend interfaces (e.g., `started_at`, `agent_version_name`).
5. **Trace Styling:** Fixed risk-level case sensitivity issues, ensuring high/critical risk tool calls highlight properly.
6. **Remediation Verification:** Fixed a bug where `tool_schema` patches weren't passed into the verification sandbox.
