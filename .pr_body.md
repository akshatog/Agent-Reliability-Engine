### 🧪 Key Fixes Applied

1. **LLM Provider Overhaul:** The previous Gemini models were failing to return properly structured JSON for adversarial generation. Moving to Groq's `AsyncGroq` client with `response_format={"type": "json_object"}` completely resolved the `404` parsing errors during scenario generation.
2. **Red Team Navigation:** Replaced static `<a href="#scenarios">` elements with stateful React buttons tied to `useState<Tab>('console')`. Updated `globals.css` to ensure buttons inherit correct navigation styling.
3. **Trace Badge Contrast:** Fixed an issue where trace steps rendered without background colors because the CSS class `elevated` did not exist. Replaced with `safe` (emerald) and `danger` (rose).
